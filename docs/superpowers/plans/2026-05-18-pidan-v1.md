# 皮蛋 v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 Pidan v1：一个 Windows 桌面悬浮桌宠，通过 Claude Code Hook 实时显示当前会话状态（Working / Waiting / Done / Failed / Idle），点击皮蛋展开多会话列表，关键事件弹气泡 + Windows Toast 提醒。

**Architecture:** Tauri 2 单进程应用。Rust 后端跑 axum HTTP server（127.0.0.1，端口握手文件）接收 Claude Code Hook 投递的事件；状态机维护 Session 集合并通过 Tauri event 推送给前端；前端用 Vanilla HTML/CSS/JS，emoji 皮肤渲染皮蛋本体 + 气泡 + 面板窗口。Toast 用 `tauri-plugin-notification`，托盘用 Tauri 2 内置 tray API。

**Tech Stack:** Rust (tauri 2.x, axum 0.7, tokio, serde, tracing, anyhow), TypeScript-less Vanilla JS, Vite (前端构建), Tauri CLI 2.x.

**Spec:** `docs/superpowers/specs/2026-05-17-pidan-design.md`

**仓库根：** `D:\vib-coding-pet`

- [ ] **Step 1：写测试 + 实现（同时写，因为接口在测试里设计）**

  创建 `src-tauri/src/state_machine.rs`：

  ```rust
  use crate::hook_event::{HookEvent, HookEventType};
  use crate::types::{Session, Source, State, state_priority};
  use chrono::Utc;
  use std::collections::HashMap;
  use std::path::Path;

  /// Pure state container. No I/O, no async — easy to unit-test.
  #[derive(Debug, Default)]
  pub struct AppState {
      sessions: HashMap<String, Session>,
  }

  impl AppState {
      pub fn new() -> Self { Self::default() }

      pub fn sessions(&self) -> Vec<Session> {
          let mut v: Vec<Session> = self.sessions.values().cloned().collect();
          v.sort_by(|a, b| b.last_change.cmp(&a.last_change));
          v
      }

      /// Pick the most "urgent" state across all sessions, for pet's main mood.
      pub fn main_state(&self) -> State {
          self.sessions.values()
              .map(|s| s.state)
              .max_by_key(|s| state_priority(*s))
              .unwrap_or(State::Idle)
      }

      pub fn ingest_hook(&mut self, evt: HookEvent) -> Vec<StateChange> {
          let id = format!("cc:{}", evt.session_id);
          let now = Utc::now();
          let project = evt.project.clone()
              .or_else(|| evt.cwd.as_deref().and_then(project_from_path))
              .unwrap_or_else(|| "unknown".into());

          match evt.event_type {
              HookEventType::SessionStart => {
                  let session = Session {
                      id: id.clone(),
                      source: Source::ClaudeCodeHook,
                      agent: "claude-code".into(),
                      project,
                      title: evt.prompt.clone(),
                      state: State::Working,
                      last_change: now,
                      last_seen: now,
                  };
                  self.sessions.insert(id.clone(), session);
                  vec![StateChange::Created(id)]
              }
              HookEventType::UserPromptSubmit => self.transition(&id, State::Working, now, evt.prompt),
              HookEventType::Stop => self.transition(&id, State::Done, now, None),
              HookEventType::Notification => self.transition(&id, State::Waiting, now, None),
              HookEventType::SessionEnd => {
                  if self.sessions.remove(&id).is_some() {
                      vec![StateChange::Removed(id)]
                  } else {
                      vec![]
                  }
              }
          }
      }

      fn transition(&mut self, id: &str, new: State, now: chrono::DateTime<Utc>, title: Option<String>) -> Vec<StateChange> {
          if let Some(s) = self.sessions.get_mut(id) {
              let from = s.state;
              if from != new {
                  s.state = new;
                  s.last_change = now;
                  s.last_seen = now;
                  if title.is_some() { s.title = title; }
                  return vec![StateChange::Transitioned { id: id.into(), from, to: new }];
              } else {
                  s.last_seen = now;
                  return vec![];
              }
          }
          // Session unknown — treat as if created in Working / target.
          let session = Session {
              id: id.into(),
              source: Source::ClaudeCodeHook,
              agent: "claude-code".into(),
              project: "unknown".into(),
              title,
              state: new,
              last_change: now,
              last_seen: now,
          };
          self.sessions.insert(id.into(), session);
          vec![StateChange::Created(id.into())]
      }
  }

  #[derive(Debug, Clone, PartialEq, Eq)]
  pub enum StateChange {
      Created(String),
      Transitioned { id: String, from: State, to: State },
      Removed(String),
  }

  fn project_from_path(p: &str) -> Option<String> {
      Path::new(p).file_name().and_then(|s| s.to_str()).map(String::from)
  }

  #[cfg(test)]
  mod tests {
      use super::*;

      fn evt(et: HookEventType, sid: &str) -> HookEvent {
          HookEvent {
              event_type: et,
              session_id: sid.into(),
              cwd: Some("D:/proj/foo".into()),
              project: None,
              prompt: None,
              raw: serde_json::Value::Null,
          }
      }

      #[test]
      fn session_start_creates_session_in_working() {
          let mut s = AppState::new();
          let changes = s.ingest_hook(evt(HookEventType::SessionStart, "a"));
          assert_eq!(changes.len(), 1);
          assert_eq!(s.sessions.len(), 1);
          let session = s.sessions.values().next().unwrap();
          assert_eq!(session.state, State::Working);
          assert_eq!(session.project, "foo");
      }

      #[test]
      fn notification_transitions_to_waiting() {
          let mut s = AppState::new();
          s.ingest_hook(evt(HookEventType::SessionStart, "a"));
          let changes = s.ingest_hook(evt(HookEventType::Notification, "a"));
          assert_eq!(changes.len(), 1);
          assert!(matches!(&changes[0], StateChange::Transitioned { to: State::Waiting, .. }));
      }

      #[test]
      fn stop_transitions_to_done() {
          let mut s = AppState::new();
          s.ingest_hook(evt(HookEventType::SessionStart, "a"));
          s.ingest_hook(evt(HookEventType::Stop, "a"));
          assert_eq!(s.sessions.values().next().unwrap().state, State::Done);
      }

      #[test]
      fn session_end_removes_session() {
          let mut s = AppState::new();
          s.ingest_hook(evt(HookEventType::SessionStart, "a"));
          let changes = s.ingest_hook(evt(HookEventType::SessionEnd, "a"));
          assert!(matches!(&changes[0], StateChange::Removed(_)));
          assert!(s.sessions.is_empty());
      }

      #[test]
      fn main_state_picks_highest_priority() {
          let mut s = AppState::new();
          s.ingest_hook(evt(HookEventType::SessionStart, "a"));   // Working
          s.ingest_hook(evt(HookEventType::SessionStart, "b"));
          s.ingest_hook(evt(HookEventType::Notification, "b"));   // b -> Waiting
          assert_eq!(s.main_state(), State::Waiting);
      }

      #[test]
      fn duplicate_event_no_change() {
          let mut s = AppState::new();
          s.ingest_hook(evt(HookEventType::SessionStart, "a"));
          let changes = s.ingest_hook(evt(HookEventType::UserPromptSubmit, "a"));
          assert!(changes.is_empty(), "Working -> Working should not emit change");
      }

      #[test]
      fn unknown_session_event_creates_session() {
          let mut s = AppState::new();
          let changes = s.ingest_hook(evt(HookEventType::Notification, "ghost"));
          assert_eq!(changes.len(), 1);
          assert_eq!(s.sessions.values().next().unwrap().state, State::Waiting);
      }
  }
  ```

  ```rust
  use crate::hook_event::HookEvent;
  use crate::state_machine::{AppState, StateChange};
  use anyhow::Result;
  use axum::{extract::State, routing::post, Json, Router};
  use std::net::TcpListener;
  use std::sync::Arc;
  use tokio::sync::{Mutex, broadcast};

  pub type SharedState = Arc<Mutex<AppState>>;

  #[derive(Clone)]
  pub struct HttpDeps {
      pub state: SharedState,
      pub change_tx: broadcast::Sender<StateChange>,
  }

  pub fn router(deps: HttpDeps) -> Router {
      Router::new()
          .route("/event", post(handle_event))
          .route("/health", post(|| async { "ok" }))
          .with_state(deps)
  }

  async fn handle_event(
      State(deps): State<HttpDeps>,
      Json(evt): Json<HookEvent>,
  ) -> &'static str {
      let mut s = deps.state.lock().await;
      let changes = s.ingest_hook(evt);
      drop(s);
      for c in changes {
          let _ = deps.change_tx.send(c);
      }
      "ok"
  }

  pub async fn serve(listener: TcpListener, deps: HttpDeps) -> Result<()> {
      let std_listener = listener;
      std_listener.set_nonblocking(true)?;
      let tokio_listener = tokio::net::TcpListener::from_std(std_listener)?;
      tracing::info!("http server listening on {}", tokio_listener.local_addr()?);
      axum::serve(tokio_listener, router(deps)).await?;
      Ok(())
  }
  ```

  const bubblesEl = document.getElementById("bubbles")!;
  const MAX_BUBBLES = 3;

  interface StateChange {
      kind: "created" | "transitioned" | "removed";
      id?: string;
      from?: State; to?: State;
  }

  function bubbleFor(change: StateChange, sessions: Session[]): string | null {
      if (change.kind !== "transitioned") return null;
      const sess = sessions.find(s => s.id === change.id);
      const project = sess?.project ?? "?";
      if (change.to === "waiting") return `📨 ${project} 在等你回复`;
      if (change.to === "done"  && change.from === "working") return `✅ ${project} 跑完啦`;
      if (change.to === "failed") return `❌ ${project} 出错了`;
      return null;
  }

  function showBubble(text: string) {
      while (bubblesEl.children.length >= MAX_BUBBLES) {
          bubblesEl.removeChild(bubblesEl.firstChild!);
      }
      const div = document.createElement("div");
      div.className = "bubble";
      div.textContent = text;
      bubblesEl.appendChild(div);
      setTimeout(() => div.classList.add("fade"), 2700);
      setTimeout(() => div.remove(), 3500);
  }

  // wrap render to also pop bubble on snapshot.last_change
  listen<Snapshot & { last_change?: StateChange }>("pidan://snapshot", (e) => {
      currentSnap = e.payload;
      render();
      if (e.payload.last_change) {
          const text = bubbleFor(e.payload.last_change, e.payload.sessions);

  ```bash
  #!/usr/bin/env bash
  # pidan-hook.sh — Claude Code Hook bridge to Pidan desktop pet.
  # Usage: pidan-hook.sh <EventType>
  #   EventType: SessionStart | UserPromptSubmit | Notification | Stop | SessionEnd
  # Reads Claude Code's hook JSON from stdin (when applicable) and forwards to Pidan.

  set +e
  EVENT="${1:-}"
  PORT_FILE="${APPDATA:-$HOME/.config}/pidan/port"
  if [ ! -f "$PORT_FILE" ]; then exit 0; fi
  PORT="$(cat "$PORT_FILE" 2>/dev/null)"
  if [ -z "$PORT" ]; then exit 0; fi

  STDIN_JSON=""
  if ! [ -t 0 ]; then
      STDIN_JSON="$(cat)"
  fi

  # Extract session_id and cwd from stdin JSON if present (best-effort, no jq dep).
  SID=""
  CWD=""
  if [ -n "$STDIN_JSON" ]; then
      SID="$(printf '%s' "$STDIN_JSON" | grep -oE '"session_id"[[:space:]]*:[[:space:]]*"[^"]*"' | head -1 | sed 's/.*"\([^"]*\)"$/\1/')"
      CWD="$(printf '%s' "$STDIN_JSON" | grep -oE '"cwd"[[:space:]]*:[[:space:]]*"[^"]*"' | head -1 | sed 's/.*"\([^"]*\)"$/\1/')"
  fi
  [ -z "$SID" ] && SID="manual-$$"

  PAYLOAD=$(cat <<EOF
  {"event_type":"$EVENT","session_id":"$SID","cwd":"$CWD","raw":${STDIN_JSON:-null}}
  EOF
  )

  curl -sS -m 1 -X POST "http://127.0.0.1:$PORT/event" \
       -H "Content-Type: application/json" \
       -d "$PAYLOAD" >/dev/null 2>&1 || true

  exit 0
  ```

  """Manual E2E driver. Run AFTER `npm run tauri dev` is up."""
  import json, os, time, urllib.request, sys

  PORT_FILE = os.path.join(os.environ["APPDATA"], "pidan", "port")

  def post(event_type, sid, cwd="D:/proj/foo"):
      port = open(PORT_FILE).read().strip()
      data = json.dumps({"event_type": event_type, "session_id": sid, "cwd": cwd}).encode()
      req = urllib.request.Request(f"http://127.0.0.1:{port}/event",
                                   data=data, headers={"Content-Type": "application/json"})
      with urllib.request.urlopen(req, timeout=2) as r:
          return r.status

  def main():
      print("→ SessionStart"); print(post("SessionStart", "e2e-1")); time.sleep(0.8)
      print("→ Notification"); print(post("Notification", "e2e-1")); time.sleep(0.8)
      print("→ Stop");         print(post("Stop", "e2e-1"));         time.sleep(0.8)
      print("→ SessionStart 2"); print(post("SessionStart", "e2e-2", "D:/proj/bar")); time.sleep(0.8)
      print("→ Notification 2"); print(post("Notification", "e2e-2")); time.sleep(0.8)
      print("done — observe pet window for waiting state on bar")

  if __name__ == "__main__": main()
